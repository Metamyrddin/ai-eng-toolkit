## How to read these results (hand-written; numbers refer to the tables above)

* **SmolLM2-360M vs 135M on ARC-Easy:** the 360M model scores higher in both metrics, but with 200 questions the paired 95 % bootstrap interval for the difference includes 0 and McNemar's exact test gives p > 0.1. *We cannot claim the larger model is better on this sample* — the honest conclusion is "consistent with a small improvement, not demonstrated at n = 200". Running with the full test set (`--n 2376`, ARC-Easy's test size) would shrink the interval ~3×.
* **`acc` vs `acc_norm`** differ by several points for the same model and prompts: the choice of scoring rule alone moves the headline number more than the 135M→360M gap. Always state which one you report.
* **Seeds / protocol variance:** at n = 100 per seed, the per-seed score of one configuration has a standard deviation of about 0.02–0.06 across seeds (`std` column) just from *which* 100 items and *which* exemplars are drawn. Adding 1 or 3 exemplars improves `acc_norm` over zero-shot by ~0.06 and the paired interval over 5 seeds excludes 0 for both; the 1-shot vs 3-shot difference is not resolved.
* **Contamination:** ARC-Easy test vs ARC-Easy train flags a small number of near-duplicate questions *inside the benchmark itself* (benchmarks do contain such overlaps). Against WikiText-2 nothing is flagged — which is unsurprising and is **not** evidence about the models' real pre-training data. The self-test table is the important part: with an 8-gram detector, recall collapses once ~10–20 % of an item's words are changed (every 8-gram needs 8 consecutive unchanged words), so paraphrased leakage is invisible to this method. Embedding-based or LLM-based detection is needed for that; none is provided here.
* **Limits:** ARC-Easy only; the 8-gram size and the 0.5 threshold are our choices (GPT-3 used 13-grams on its own, much larger corpora); the planted-item self-test uses random token replacement, not natural paraphrase.
