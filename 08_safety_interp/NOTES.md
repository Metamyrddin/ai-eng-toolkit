## How to read these results (hand-written)

* **Red-team table:** with 6–12 prompts per cell the Wilson intervals are very wide; only the large gaps are meaningful. *Qwen2.5-0.5B-Instruct* refuses all direct harmful requests in this set while both SmolLM2 instruct models refuse none by our regex — we cannot say *why* from this experiment (training data and recipes differ). "Not refusing" is not "dangerous": the saved transcripts are truncated to their first 160 characters and often incoherent for the smallest model.
* **Prompt injection / canary leak:** all three models follow injected instructions or leak the canary at substantial rates. The ranking between models on these two columns is **not** statistically resolved (intervals overlap heavily).
* **Wrapper effect:** the paired table counts how many requests flipped from refused to not-refused (or the reverse) when wrapped in a role-play prefix: at most one of six flips for any model — too few pairs to claim an effect.
* **Logit lens:** on the "Eiffel Tower … city of" prompt the right answer (" Paris") is ranked in the thousands until the last few layers and then jumps to rank 1 around layer index 28 (the model has 30 layers; index 0 is the embedding output): the factual recall appears only late. Intermediate-layer top tokens (`' '`, `','`) are junk — this is the known weakness of the plain logit lens in early/middle layers (Belrose et al. 2023). The last-layer lens equals the model's own output (tested).
* **Activation patching:** the corrupted prompt differs from the clean one only at the token " France"/" Italy", so patching that position at any early layer trivially restores the answer (recovery ≈ 1). The informative change is at block index 23 (patching index l = output of transformer block l, 0-based): from then on, patching the *last* token's residual stream (" is") restores the answer and patching " France" no longer does — i.e. in this model the country information has been moved to the final position by layer ~23. This is one prompt pair on one small model; it illustrates the method and is not a circuit analysis. The identity check (patching everything reproduces the clean logits exactly) passed with error 0.
