# Project structure

This page is a map of the whole project.
It shows every folder and every file, and it explains each one in a single sentence.
If you are new here, start with `README.md`, then read this page, and then open the folder of the area that interests you.

## How the project is organised

The project has three kinds of folders:

- The eight numbered folders (`01_` to `08_`) are the areas, and each area is a small course with code, tests, results and a cloud path.
- The folders `common/`, `tools/` and `tests/` hold the helper code, the helper programs and the tests that all areas share.
- The folder `skills_drafts/` holds one short how-to guide per area.

Every area folder has the same shape:

- The file `README.md` explains the ideas and the commands.
- The file `NOTES.md` explains how to read the results.
- The file `RESULTS.md` shows the measured numbers, and it is generated by a program.
- The folder `results/` holds the raw numbers from the real runs.
- The folder `cloud/` holds the untested GPU path.
- The Python files hold the experiments, and each of them starts with a plain-English description.

Some folders are created on your computer while you work, and Git does not upload them. They are `.venv/` (the virtual environment), `.hf_cache/` (the downloaded models), `.bin/` (the llama.cpp programs), `outputs/` (trained models), `tools/gpu/generated/` (notebooks made by `make_notebooks.py`) and every `__pycache__/` folder.
